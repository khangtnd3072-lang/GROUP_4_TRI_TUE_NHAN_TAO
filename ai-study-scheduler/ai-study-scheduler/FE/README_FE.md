# Frontend

Frontend của dự án dùng **HTML + CSS + JavaScript thuần**, không dùng React, Vue, Angular, npm hay framework CSS.

- `index.html`: giao diện chính.
- `css/style.css`: toàn bộ style responsive.
- `js/api.js`: lớp gọi REST API đến Backend.
- `js/app.js`: state phía trình duyệt, render giao diện và xử lý sự kiện.
- `run_frontend.bat`: chạy static server ở cổng `5500`.

Backend mặc định được gọi tại `http://127.0.0.1:8000/api`.
