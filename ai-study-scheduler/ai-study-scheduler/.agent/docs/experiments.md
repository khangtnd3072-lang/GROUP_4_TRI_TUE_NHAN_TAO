# Experiment Design

Use the same input data for both Genetic Algorithm and Earliest Deadline First.

Recommended scenarios:

1. Low load: few tasks, abundant availability.
2. Tight deadlines: multiple tasks due within a few days.
3. Limited availability: task hours exceed feasible capacity.
4. High-priority competition: multiple urgent/high-priority tasks.
5. Large case: many tasks and many slots.

Collect at least:

- fitness;
- fully scheduled task count;
- full schedule rate;
- average completion ratio;
- allocated study hours;
- generations run;
- execution time (add measurement for the final experiment if needed).

Do not claim GA is better until repeated executions/test cases support that conclusion.
